# Pre-registration: H5 (remainder coupling)

Written 2026-10-14, **before any H5 measurement was run on any model**. The experiment code
(`hlens/experiments/remainder_coupling.py`) records the SHA-256 of this file in every result file
and refuses to run the real-model arm unless the randomized-model arm was already run under the
same hash. Do not edit this file after the first run; amend by adding a dated addendum below.

## Hypothesis (research notes §3, H5)
The non-J-space remainder is not inert: it is coupled, through second-order terms, to the atoms the
sparse pursuit selected — `r̂ᵀ H a_j` is above null for selected atoms — i.e. the remainder gates or
amplifies the sparse decomposition rather than being orthogonally separable from it.

## Setup (fixed)
- Model: Qwen3.5-4B, fp32, eager attention (the real arm); weight-randomized copy, `reinit`, seed 0,
  with the lens already fitted for it (`results/nulls/lens_randomized_reinit_s0_L16.pt`) (the null arm).
- Contexts: WikiText-103 prompts with indices **200–239** of `jlens.examples.load_wikitext_prompts(240)`
  (disjoint from every earlier gate and from the null-lens fit), 128 tokens, **5 random valid
  positions per prompt** (`valid_position_mask`, default skip), numpy/torch seed 0 → **200 contexts**.
  Layer **ℓ = 16**, residual `x` at the context's position.
- Dictionary: unit-norm J-lens vectors `u_t J_ℓ` of the whole vocabulary of the arm's own model/lens.
- Decomposition: `decompose(x, dictionary, k=25)` → selected atoms `a_j` (unit), remainder
  `ρ = x − J-space component`, `r̂ = ρ/‖ρ‖`. Contexts with ‖ρ‖/‖x‖ < 0.05 are excluded (reported).
- Scalar `f` (**primary**): the logit of the arm's own top-1 next-token prediction at that position,
  as a function of `x` (layers ℓ→final, unembed; position-restricted as in `hlens.contexts`).
- Coupling vector `w = H_f r̂` (one forward-over-reverse HVP). For a unit direction `a`:
  `s(a) = |⟨w, a⟩| / ‖w‖`  (the cosine magnitude between the curvature response to the remainder and `a`;
  `r̂ᵀ H a = ⟨H r̂, a⟩` by symmetry).
- Control atoms: the **25 highest-correlation (`⟨a, x⟩`) atoms among those NOT selected** by the
  pursuit, same context. They are about as aligned with `x` as the selected ones but were not selected.

## Primary statistic and test (the only one that decides the hypothesis)
Per context `c`: `d_c = mean_{selected} s(a) − mean_{control} s(a)`. `T = mean_c d_c`.
* **Test A (specificity of selection):** one-sided sign-flip permutation test on the `d_c`
  (10,000 permutations, seed 0), H1: `T > 0`. Criterion: **p < 0.01**.
* **Test B (above the weight-randomized null):** the identical computation on the randomized model
  (`T_null`, its `d_c`); criterion: the 95% percentile-bootstrap CI (10,000 resamples of contexts in
  each arm, seed 0) of `T_real − T_null` **excludes 0 and is positive**.

**H5 is supported iff both A and B hold.** Otherwise it is **not supported** (A fails: the remainder
couples no more to selected atoms than to equally-aligned unselected ones; B fails: the effect is
reproduced by a network with no learned structure). Results are reported either way.

## Secondary, exploratory (reported, never used to decide)
1. Same statistic with `f_j` = the logit of atom `j`'s own token (`w_j = H_{f_j} r̂`).
2. `s` for selected atoms vs the analytic random-direction level `E|cos| ≈ 0.8/√d_model ≈ 0.016`.
3. Dependence of `s` on the pursuit coefficient; layers 12 and 20; k = 10.
4. Whether `‖H r̂‖` relative to `‖∇f‖` (how much the remainder curves the gradient) differs by arm.

## Known limits (stated in advance)
One layer, one scalar, one dictionary-construction (`u_t J_ℓ` at `h_ref = ones`, a documented caveat),
a randomized null with a 30-prompt lens, 200 contexts (about 5,000 selected-atom measurements; contexts,
not atoms, are the unit of inference). "Coupling" here is directional alignment of the curvature
response; it says nothing about causal effect on outputs.

## Addendum 1 (2026-10-14, written AFTER the first run; read it as a post-hoc correction, not as a clean pre-registration)
**First run (the pre-registered test A/B above), recorded in `results/h5/{real,null}.json` and `analysis.json`:**
`T_real = −0.0024`, `T_null = +0.0010`; test A p = 0.9999 (fail), test B CI of `T_real − T_null` =
[−0.0049, −0.0019] (fail) → **H5 not supported as pre-registered.**

**A flaw in the control, found after seeing the sign.** The pursuit's optimality conditions make the
remainder exactly orthogonal to the selected atoms (`⟨a_j, ρ⟩ = 0` on the support), whereas the control atoms
(the next-best correlated with `x ≈ ρ` + a small J-space part) are *not* orthogonal to `r̂`. Any component
of `w = H r̂` along `r̂` itself therefore inflates `s(a)` for controls and not for selected atoms; a negative
`T` is what that geometry predicts even under real coupling. (Post-hoc, against the analytic random-direction
level `E|cos| = 0.0158`: selected atoms 1.45× [1.39, 1.51] in the real model vs 1.14× [1.11, 1.18] in the null;
controls 1.60× vs 1.08×; no dependence on pursuit coefficient, Spearman 0.045.)

**Corrected statistic (decided after the fact; the follow-up arms are labelled `*_v2`).** Remove the `r̂`
direction from the response: `w⊥ = w − ⟨w, r̂⟩ r̂`, and from every atom: `a⊥ = a − ⟨a, r̂⟩ r̂` normalised
(identity for selected atoms). `s⊥(a) = |⟨w⊥, a⊥⟩| / (‖w⊥‖ ‖a⊥‖)`, `d⊥_c = mean_sel s⊥ − mean_ctrl s⊥`,
`T⊥ = mean d⊥_c`. **Tests A⊥ (sign-flip, p < 0.01) and B⊥ (CI of `T⊥_real − T⊥_null` > 0), same contexts,
same arms, same criteria.** Supported-after-correction iff A⊥ ∧ B⊥. Everything else unchanged. Because it
was designed after seeing the data it cannot overturn the first verdict on its own: it can only say
whether the pre-registered null result was an artifact of the control.
